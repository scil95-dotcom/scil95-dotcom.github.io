# Alfio Scilio — Portfolio

A responsive, buildless personal portfolio for fully remote opportunities in AI-assisted automation, Python tooling and digital operations.

**Live:** https://scil95-dotcom.github.io/ · **GitHub:** https://github.com/scil95-dotcom · **LinkedIn:** https://www.linkedin.com/in/alfio-scilio-9157a1238/

## Local preview

```bash
python3 -m http.server 8091
```

Open http://localhost:8091. No dependencies, analytics, cookies or backend. The evidence console changes project descriptions and review checklists; it does not execute Python in the browser.

## Design & review

- Responsive layout, semantic sections and keyboard-operated tabs.
- Visible focus styles and reduced-motion support.
- Contact information published on the owner's explicit request.
- AI-assisted personal projects, with synthetic examples and explicit scope limits.
- Original SVG assets; no private repository files or working data included.

GitHub Pages serves the root of `main`. The four linked lab repositories contain executable code, tests and detailed reproducibility instructions. Private business experiments remain private and stopped.
